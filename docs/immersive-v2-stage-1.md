# PARABLE Immersive V2 — Stage 1

## Goal
Rebuild the PARABLE opening around the interaction rhythm demonstrated in the supplied Framer reference while keeping PARABLE's own identity, copy, backend data and media.

## Stage 1 acceptance target
- oversized product statement before any dashboard UI
- compact product navigation with primary and secondary actions
- large cinematic product-film frame immediately beneath the hero
- motion prototype that communicates manuscript → story intelligence → story covers → scene → director → timeline
- real story titles populated from `/api/projects`
- backend-backed New Story flow remains functional
- mobile layout is first-class
- reduced-motion fallback remains usable
- existing production `main` stays untouched until visual approval

## Explicitly deferred
- liquid/WebGL page transition (Stage 2)
- spatial/3D story-cover universe (Stage 3)
- immersive story opening (Stage 4)
- writer/director workspace redesign

## Hero film
The current hero film is a zero-cost DOM/CSS motion prototype. The final generated cinematic footage is intentionally not purchased without approval. Current connected video pricing was approximately $0.025/sec, so a 10-second render would be about $0.25 before retries.
