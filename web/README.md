# PARABLE Web Mirror

This is the independent website working environment for PARABLE.

Purpose: keep development moving even when Floot build credits are exhausted. GitHub is the source of truth; the website stays available for testing, and compatible changes can be synced back into Floot when credits reset.

Current live environment: Hatchable project `parable`.

Day 1 features mirrored here:
- cinematic writer workspace
- persistent project list
- New Story flow
- audience scope, setting and story period grounding
- seven modular engine statuses

The production concept remains platform-agnostic: Story, Film, Culture, Location, Performance/Audio, Rendering and Continual Learning are separate layers.
